# Test Execution Reports Directory

This directory stores automated HTML test execution reports generated by Pytest (`pytest-html`).

## Report Generation Commands

To generate a self-contained HTML execution report locally:

```bash
# Recommended command (Windows PowerShell / Cross-Platform):
python -m pytest --html=reports/report.html --self-contained-html

# Standard command (if pytest script is in system PATH):
pytest --html=reports/report.html --self-contained-html
```

## Sample Report Output Summary
- **Total Tests Run:** 3
- **Passed:** 3 (100% Pass Rate)
- **Failed:** 0
- **Execution Duration:** ~7.04 seconds

The generated HTML report `reports/report.html` is self-contained and contains test execution metadata, environment details, duration metrics, and assertion results.
